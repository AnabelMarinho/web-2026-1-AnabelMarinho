## ✿ Sobre o Projeto

Para ser um bom profissional, é necessário ir além da grade curricular, explorando novas tecnologias, idiomas e ferramentas.

A **Plataforma Para Expansão de Conhecimentos** foi criada com o objetivo de permitir que alunos ministrem cursos e compartilhem conhecimento dentro de um ambiente colaborativo.

⊹ Aprendizado contínuo  
⊹ Colaboração entre alunos  
⊹ Desenvolvimento de comunicação e liderança  
⊹ Emissão de certificados e horas complementares  

---

## ⪩⪨ Tipos de Usuários

⬦ Discente (Instrutor) → cria e ministra cursos  
⬦ Discente (Aluno) → se inscreve em cursos  
⬦ Docente → sugere ideias de cursos  
⬦ Técnico → gerencia salas e infraestrutura  

---

## ✦ Uso de IA Generativa

A IA será utilizada como suporte para:

⊹ Gerar resumos automáticos de cursos e turmas  
⊹ Auxiliar na divulgação de experiências acadêmicas  
⊹ Organizar conteúdos disponibilizados  

---

## ⋆✴︎˚｡⋆ Arquitetura do Sistema

⬦ Frontend: Angular + AWS Amplify  
⬦ Backend: Java (Spring Boot) + AWS Lambda  
⬦ Banco de Dados: Amazon RDS (MySQL)
